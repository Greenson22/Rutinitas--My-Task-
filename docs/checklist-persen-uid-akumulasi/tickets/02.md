# 02: Kalkulasi Terpusat dan Sinkronisasi Persentase History-Card

**What to build:** Persentase bar chart di halaman History kini identik dengan persentase progress bar di card grid. Satu kelas utilitas statis (`ChecklistCalculationHelper`) menjadi satu-satunya sumber kebenaran kalkulasi persentase di seluruh aplikasi. Item yang dinonaktifkan (disabled) tidak lagi terhitung di persentase — baik di card grid, dialog controller, maupun history. Item bertipe progress dan countdown dihitung secara proporsional di history (sama seperti yang sudah berjalan di card grid). Hanya leaf nodes (item tanpa anak) yang masuk kalkulasi.

**Blocked by:** 01 (Fondasi Model Data — UUID dan isDisabled).

**Status:** ready-for-agent

- [ ] Kelas `ChecklistCalculationHelper` tersedia dengan empat method statis: `countTotalItems`, `countFinishedItems` (untuk `SubSubjectItem`), `countTotalFromLog`, `countFinishedFromLog` (untuk `DailyLogEntry`)
- [ ] Kalkulasi di card grid menggunakan `ChecklistCalculationHelper` (mengganti fungsi inline `_countTotalItems`/`_countFinishedItems`)
- [ ] Kalkulasi di dialog controller (`updateSubjectOverallProgress`) menggunakan `ChecklistCalculationHelper`
- [ ] Kalkulasi di history screen menggunakan `ChecklistCalculationHelper` (mengganti `_countTotal`/`_countFinished` yang int-based)
- [ ] Callback `HistoryBarChart` berubah dari `int Function(List<DailyLogEntry>)` ke `double Function(List<DailyLogEntry>)`
- [ ] Tampilan `finished / total Selesai` di list entry history menggunakan format double (bilangan bulat tanpa desimal, pecahan 1 desimal)
- [ ] Buat card dengan campuran: item normal selesai, item progress 50/100, item countdown sisa 30/100, dan 1 item disabled → persentase card grid = persentase bar history setelah "Simpan Hari Ini"
- [ ] Nonaktifkan item → Simpan Hari Ini → persentase history naik (denominator berkurang)
- [ ] Data history lama (tanpa `isDisabled` di log) tetap tampil normal (default false → semua terhitung seperti sebelumnya)
- [ ] `flutter analyze` bersih untuk semua file yang diubah
