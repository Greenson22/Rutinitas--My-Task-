# 04: Tampilan Jumlah Akumulasi di Tree View

**What to build:** Saat membuka dialog checklist, item kecil yang terkait ke item besar di card lain menampilkan angka akumulasi terkini di sebelah ikon ⚡, dengan format `(currentValue/targetValue)`. Teks ini membantu pengguna melihat "sudah berapa jumlah totalnya" tanpa harus membuka card target secara manual. Tampilan hanya muncul di dalam dialog checklist (tree view), bukan di card grid luar. Angka update saat nilai berubah.

**Blocked by:** 01 (Fondasi Model Data), 03 (Kaitan Akumulasi Berbasis ID Unik).

**Status:** ready-for-agent

- [ ] `ChecklistTreeView` menerima parameter callback opsional `resolveExternalAccumulationText` bertipe `String? Function(SubSubjectItem)?`
- [ ] Checklist dialog menyediakan callback yang melakukan lookup item target (ID-first, name-fallback) dari `allAvailableSubjects` dan mengembalikan teks format `(currentValue/targetValue)`
- [ ] Teks akumulasi tampil di sebelah ikon ⚡ pada mode non-edit, hanya jika item memiliki kaitan eksternal aktif dan item target berhasil ditemukan
- [ ] Teks akumulasi juga tampil di mode edit (setelah nama item, sebelum ikon edit)
- [ ] Item tanpa kaitan eksternal → tidak ada teks tambahan (perilaku tidak berubah)
- [ ] Item dengan kaitan eksternal tapi target tidak ditemukan → hanya ikon ⚡ tanpa teks (perilaku seperti sebelumnya)
- [ ] Buat Item B (progress) di Card Y, kaitkan ke Item A (progress 45/100) di Card X → buka dialog Card Y → di sebelah nama Item B muncul `⚡ (45/100)`
- [ ] Increment Item B → teks akumulasi berubah sesuai nilai baru item target
- [ ] Callback diteruskan secara rekursif ke children `ChecklistTreeView`
- [ ] `flutter analyze` bersih untuk semua file yang diubah
