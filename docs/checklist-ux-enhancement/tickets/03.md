# 03: Helper colorFromItemName (Pure Function)

**What to build:** Buat fungsi murni (pure function) `colorFromItemName(String name) → Color` di file helper terpisah dalam direktori utilitas checklist. Fungsi ini menerima nama item sebagai string dan mengembalikan objek `Color` secara **deterministik** — nama yang sama selalu menghasilkan warna yang sama, tanpa state eksternal, tanpa side effect.

Algoritma yang digunakan (dari prototype di SPEC):
- Hitung hash djb2 dari `name.codeUnits`
- Ambil `hash % 360` sebagai nilai hue (0–360)
- Konversi ke HSL dengan saturation tetap 0.6 dan lightness tetap 0.55
- Kembalikan sebagai `Color`

Fungsi ini ditempatkan di file helper tersendiri (bukan sebagai method private widget) agar bisa diuji secara unit tanpa konteks widget dan agar bisa diimpor oleh `HistoryBarChart` di tiket 04.

Unit test memverifikasi determinisme, variasi antar nama, dan robustness terhadap edge case.

**Blocked by:** None (can start immediately)
