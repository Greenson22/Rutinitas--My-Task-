# 02: Color Wheel Interaktif di ChangeColorDialog

**What to build:** Dialog ubah warna card checklist (`ChangeColorDialog`) diperlengkapi dengan color wheel interaktif yang ditempatkan di antara live preview dan input HEX. Color wheel dan input HEX berjalan **sinkron dua arah**: menggeser titik pada wheel memperbarui nilai HEX secara otomatis; mengetikkan kode HEX valid (6 karakter) memindahkan posisi titik pada wheel ke warna yang sesuai. Memilih warna dari palet kuratif statis yang sudah ada juga memperbarui wheel dan HEX secara bersamaan.

Dropdown manual pemilihan warna teks ("Gelap"/"Putih") **dihapus** dari dialog. Warna teks sepenuhnya ditentukan otomatis berdasarkan kecerahan (brightness) warna background yang dipilih — gelap jika background terang, putih jika background gelap.

Layout dialog dari atas ke bawah: (1) Live Preview, (2) Color Wheel baru, (3) Input HEX, (4) Palet kuratif statis. API/contract `ChangeColorDialog` (parameter `subject` dan callback `onColorSaved`) tidak berubah. Dependency baru `flutter_colorpicker` ditambahkan ke `pubspec.yaml` — cek terlebih dahulu apakah library serupa sudah tersedia sebelum menambah dependency baru.

Test baru memverifikasi keberadaan wheel, sinkronisasi dengan HEX, penghapusan dropdown warna teks, dan auto-text-color. Test lama tidak boleh regresi.
