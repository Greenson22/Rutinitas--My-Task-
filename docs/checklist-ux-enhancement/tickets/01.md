# 01: Badge Tipe Item di Edit History

**What to build:** Di sheet edit riwayat harian (`EditHistoryEntrySheet`), setiap item yang bertipe `progress` menampilkan badge kecil bergambar ikon trending-up bertuliskan "Progress" (warna biru muda), dan setiap item bertipe `countdown` menampilkan badge bergambar ikon timer bertuliskan "Hitung Mundur" (warna oranye). Badge ditempatkan sebagai baris kedua di bawah nama item — bukan inline — agar tidak menyempitkan ruang status selector. Item bertipe `normal` tidak mendapat badge sama sekali.

Selain badge, label di depan field input nilai diperjelaskan: item `progress` menggunakan label "Nilai saat ini:" (sebelumnya "Nilai:"), item `countdown` tetap menggunakan label "Sisa:". Badge dan label yang diperbarui berlaku rekursif untuk semua level hierarki item (sub-item / children).

Semua perilaku simpan tidak berubah. Test yang sudah ada pada sheet ini tidak boleh regresi. Test baru ditambahkan untuk memverifikasi badge tampil/tidak tampil per tipe dan label input yang benar.
