# 10: Reorder, pindah tugas, dan aksi massal

**What to build:** Pengguna dapat mengubah urutan kategori dan tugas, memindahkan tugas ke kategori lain tanpa kehilangan `id`, serta melakukan aksi massal untuk mengaktifkan, menonaktifkan, atau menghapus banyak tugas sekaligus. Semua perubahan bertahan setelah reload.

**Blocked by:** 04 — Kelola tugas, jenis tugas, dan target

**Status:** ready-for-agent

- [ ] Kategori dapat diurutkan ulang dan urutan tersimpan setelah reload.
- [ ] Tugas dapat diurutkan ulang di dalam kategori dan urutan tersimpan setelah reload.
- [ ] Reorder memakai drag handle; tombol panah tetap tersedia sebagai fallback aksesibilitas.
- [ ] Tugas dapat dipindahkan ke kategori lain dan tetap mempertahankan `id`.
- [ ] Long press masuk ke mode seleksi tugas.
- [ ] Aksi massal aktif, nonaktif, dan hapus tersedia dengan konfirmasi untuk aksi destruktif.
- [ ] Mode seleksi keluar dengan jelas setelah aksi selesai.
- [ ] Widget test reorder, pindah kategori, dan aksi massal lulus.
