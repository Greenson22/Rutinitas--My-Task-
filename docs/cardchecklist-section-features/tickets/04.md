# 04: Guard — Peringatan Hapus Seksi yang Masih Berisi Item

**What to build:** Saat ini pengguna bisa menghapus seksi yang masih memiliki item tanpa peringatan apa pun — termasuk item yang tersembunyi (`isHidden = true`). Tiket ini menambahkan dialog konfirmasi yang muncul sebelum penghapusan dilanjutkan, menampilkan nama seksi dan jumlah total item yang akan ikut terhapus. Seksi kosong tetap dihapus langsung tanpa dialog.

**Blocked by:** 01 — membutuhkan field `isHidden` di `ChecklistSection` agar item tersembunyi dapat dihitung dengan benar dalam kondisi guard.

**Status:** ready-for-agent

- [ ] Mencoba menghapus seksi yang `items.isNotEmpty` → dialog konfirmasi muncul sebelum penghapusan terjadi.
- [ ] Dialog menampilkan nama seksi yang akan dihapus.
- [ ] Dialog menampilkan jumlah total item di seksi tersebut (item yang `isHidden = true` ikut dihitung).
- [ ] Jika ada item yang tersembunyi, dialog secara eksplisit menyebutkan jumlah item tersembunyi tersebut.
- [ ] Menekan "Batal" di dialog → tidak ada perubahan, seksi dan semua itemnya tetap ada.
- [ ] Menekan "Hapus Semua" di dialog → seksi dihapus dari daftar dan `saveGroupData()` dipanggil.
- [ ] Mencoba menghapus seksi yang `items.isEmpty` → langsung terhapus tanpa dialog konfirmasi.
- [ ] Widget test: hapus seksi berisi 3 item (semua visible) → dialog muncul dengan info "3 item".
- [ ] Widget test: hapus seksi berisi 2 item visible + 1 item hidden → dialog muncul dengan info "3 item (1 tersembunyi)".
- [ ] Widget test: tap "Batal" di dialog → jumlah seksi tidak berkurang.
- [ ] Widget test: tap "Hapus Semua" di dialog → seksi tidak ada lagi di widget tree.
- [ ] Widget test: hapus seksi kosong → tidak ada dialog, seksi langsung hilang.
