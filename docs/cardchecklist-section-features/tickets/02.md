# 02: Fix Bug — Mode Markdown Catatan Card Tidak Persisten

**What to build:** Saat ini, ketika pengguna mengaktifkan mode Markdown pada catatan sebuah card melalui menu opsi catatan, perubahan hanya hidup di state lokal widget dan tidak disimpan ke model data. Akibatnya, setiap kali dialog ditutup dan dibuka kembali, mode Markdown kembali ke nonaktif.

Tiket ini memperbaiki bug tersebut sehingga toggle Markdown langsung menyinkronkan status ke objek `DailySubject` milik card tersebut dan memicu propagasi perubahan ke disk — seolah pengguna mengedit catatan itu sendiri.

**Blocked by:** None (dapat dimulai sekarang, `isMarkdownEnabled` sudah ada di `DailySubject`).

**Status:** ready-for-agent

- [ ] Men-toggle Markdown ON melalui menu opsi catatan langsung memperbarui `subject.isMarkdownEnabled` menjadi `true` dan memanggil `onDataChanged()`.
- [ ] Men-toggle Markdown OFF memperbarui `subject.isMarkdownEnabled` menjadi `false` dan memanggil `onDataChanged()`.
- [ ] Menutup dialog setelah toggle ON, lalu membuka kembali dialog yang sama → catatan tampil dalam mode pratinjau Markdown (bukan teks biasa).
- [ ] Menutup dialog setelah toggle OFF, lalu membuka kembali → catatan tampil dalam mode teks biasa.
- [ ] Widget test: toggle Markdown ON → `subject.isMarkdownEnabled == true` setelah aksi.
- [ ] Widget test: toggle Markdown OFF → `subject.isMarkdownEnabled == false` setelah aksi.
- [ ] Widget test: buka dialog dengan `subject.isMarkdownEnabled = true` → pratinjau Markdown langsung ditampilkan.
- [ ] Widget test: `onDataChanged` dipanggil tepat satu kali setiap kali toggle dilakukan.
