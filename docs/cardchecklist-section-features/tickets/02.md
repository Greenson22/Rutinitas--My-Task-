# 02: Fix Bug — Mode Markdown Catatan Card Tidak Persisten

**What to build:** Saat ini, ketika pengguna mengaktifkan mode Markdown pada catatan sebuah card melalui menu opsi catatan, perubahan hanya hidup di state lokal widget dan tidak disimpan ke model data. Akibatnya, setiap kali dialog ditutup dan dibuka kembali, mode Markdown kembali ke nonaktif.

Tiket ini memperbaiki bug tersebut sehingga toggle Markdown langsung menyinkronkan status ke objek `DailySubject` milik card tersebut dan memicu propagasi perubahan ke disk — seolah pengguna mengedit catatan itu sendiri.

**Blocked by:** None (dapat dimulai sekarang, `isMarkdownEnabled` sudah ada di `DailySubject`).

**Status:** completed

- [x] Men-toggle Markdown ON melalui menu opsi catatan langsung memperbarui `subject.isMarkdownEnabled` menjadi `true` dan memanggil `onDataChanged()`.
- [x] Men-toggle Markdown OFF memperbarui `subject.isMarkdownEnabled` menjadi `false` dan memanggil `onDataChanged()`.
- [x] Menutup dialog setelah toggle ON, lalu membuka kembali dialog yang sama → catatan tampil dalam mode pratinjau Markdown (bukan teks biasa).
- [x] Menutup dialog setelah toggle OFF, lalu membuka kembali → catatan tampil dalam mode teks biasa.
- [x] Widget test: toggle Markdown ON → `subject.isMarkdownEnabled == true` setelah aksi.
- [x] Widget test: toggle Markdown OFF → `subject.isMarkdownEnabled == false` setelah aksi.
- [x] Widget test: buka dialog dengan `subject.isMarkdownEnabled = true` → pratinjau Markdown langsung ditampilkan.
- [x] Widget test: `onDataChanged` dipanggil tepat satu kali setiap kali toggle dilakukan.

## Catatan Pengerjaan
- Menambahkan method `toggleMarkdownEnabled()` pada `ChecklistDialogController` (`lib/features/checklist/presentation/checklist_detail_screen/controllers/checklist_dialog_controller.dart`) yang langsung men-toggle boolean `isMarkdownEnabled`, menyinkronkannya ke `widget.subject.isMarkdownEnabled`, dan memanggil `widget.onDataChanged()`.
- Memperbarui callback pada popup menu opsi catatan (`lib/features/checklist/presentation/checklist_detail_screen/widgets/checklist_dialog.dart`) ketika `value == 'toggle_md'` agar memanggil method `toggleMarkdownEnabled()`.
- Memperbaiki layout flex pada popup menu item Markdown dengan membungkus teks dalam `Expanded` untuk mencegah RenderFlex overflow.
- Membuat widget test komprehensif di `test/features/checklist/presentation/checklist_note_markdown_ticket_02_test.dart` yang menguji:
  1. Toggle Markdown ON mengubah model `subject.isMarkdownEnabled` menjadi `true` dan memanggil `onDataChanged` tepat 1 kali.
  2. Toggle Markdown OFF mengubah model `subject.isMarkdownEnabled` menjadi `false` dan memanggil `onDataChanged` tepat 1 kali.
  3. Membuka dialog dengan `subject.isMarkdownEnabled == true` langsung merender widget Markdown preview.
  4. Siklus buka dialog -> toggle Markdown ON -> tutup dialog -> buka dialog lagi (preview Markdown aktif) -> toggle Markdown OFF -> tutup dialog -> buka dialog lagi (tampil dalam mode biasa).
- Seluruh 91 tests pada `test/features/checklist/` lulus 100% tanpa regresi.
