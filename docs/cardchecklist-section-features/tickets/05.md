# 05: Collapse Seksi + Settings Global Default Lipatan

**What to build:** Pengguna dapat melipat (*collapse*) isi sebuah seksi langsung dari halaman detail checklist dengan mengetuk header seksi atau ikon chevron di kirinya. Ketika terlipat, hanya header yang terlihat — isi item tidak dirender. Ikon chevron berubah arah sesuai kondisi lipatan, dan ada animasi transisi yang halus.

Perilaku default lipatan dikontrol oleh dua pengaturan global di SharedPreferences yang bisa diatur pengguna dari halaman pengaturan app: apakah seksi dimulai terlipat secara default, dan apakah status lipatan per-seksi diingat antar sesi.

Perbedaan penting dari tiket 03: *collapse* tidak menghilangkan seksi dari daftar — header tetap terlihat, hanya kontennya yang dilipat.

**Blocked by:** 01 — membutuhkan field `isCollapsed` di `ChecklistSection`.
