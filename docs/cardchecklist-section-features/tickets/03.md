# 03: Sembunyikan Seksi (Section Hide)

**What to build:** Pengguna dapat menyembunyikan sebuah seksi beserta seluruh isinya dari tampilan halaman detail checklist tanpa menghapusnya. Seksi yang tersembunyi tidak muncul di daftar, namun datanya tetap utuh. Ada satu toggle global di halaman detail untuk menampilkan kembali semua seksi tersembunyi sehingga pengguna bisa men-unhide secara selektif.

Perbedaan penting: *sembunyikan* berarti seksi hilang sepenuhnya dari daftar (tidak ada trace visual) — ini berbeda dari *collapse* yang dibangun di tiket 05.

**Blocked by:** 01 — membutuhkan field `isHidden` di `ChecklistSection`.

**Status:** ready-for-agent

- [ ] Header setiap seksi memiliki ikon visibilitas (`visibility` / `visibility_off`) yang dapat di-tap.
- [ ] Mengetuk ikon tersebut men-toggle `section.isHidden` dan memanggil `saveGroupData()`.
- [ ] Seksi dengan `isHidden = true` tidak dirender di widget tree saat mode normal (tidak ada trace visual di daftar).
- [ ] Ada tombol/toggle global di halaman detail (mis. di AppBar atau area tertentu) yang, ketika diaktifkan, menampilkan seksi tersembunyi dengan indikator visual berbeda (opacity/badge "tersembunyi").
- [ ] Saat mode "tampilkan tersembunyi" aktif, ikon visibilitas pada seksi yang hidden masih bisa di-tap untuk men-unhide.
- [ ] Setelah di-unhide, seksi tampil kembali normal beserta semua item di dalamnya secara utuh.
- [ ] Status `isHidden` tersimpan ke file JSON melalui `saveGroupData()` dan bertahan setelah app restart.
- [ ] Widget test: seksi dengan `isHidden = true` → tidak ditemukan di widget tree.
- [ ] Widget test: tap ikon visibility pada seksi normal → seksi hilang dari widget tree + `section.isHidden == true`.
- [ ] Widget test: aktifkan mode "tampilkan tersembunyi" → seksi yang hidden kembali muncul di widget tree.
- [ ] Widget test: tap ikon visibility pada seksi yang sedang hidden (saat mode tampil) → seksi kembali normal (`isHidden == false`).
- [ ] Widget test: data item seksi yang dihide tidak berubah setelah proses hide–unhide.
