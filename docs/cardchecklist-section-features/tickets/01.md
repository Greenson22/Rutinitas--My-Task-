# 01: Perluas Skema `ChecklistSection` dengan Field `isHidden` & `isCollapsed`

**What to build:** Saat ini `ChecklistSection` hanya menyimpan `sectionName` dan `items`. Tiket ini menambahkan dua field boolean baru — `isHidden` dan `isCollapsed` — beserta serialisasi dan deserialisasi JSON-nya. File JSON yang dibuat sebelum tiket ini selesai harus tetap bisa dibaca tanpa error (nilai fallback `false` jika field tidak ada). Unit test serialisasi ikut divalidasi di sini.

Tiket ini adalah fondasi data untuk seluruh fitur section yang akan dibangun di tiket 03, 04, dan 05.

**Blocked by:** None (dapat dimulai sekarang).

**Status:** ready-for-agent

- [ ] `ChecklistSection.fromJson()` membaca kedua field baru dengan fallback `false` jika key tidak ada di JSON.
- [ ] `ChecklistSection.toJson()` menyertakan kedua field dalam output map.
- [ ] File JSON lama yang tidak memiliki field ini masih dapat di-parse tanpa exception.
