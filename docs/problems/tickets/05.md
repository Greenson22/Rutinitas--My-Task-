# 05: ChecklistControlPanel — Pindah Seksi Lazy-Expand

**What to build:** Tambahkan tombol "Pindah Seksi" baru ke `ChecklistControlPanel` di dalam `DailyChecklistDialog`. Daftar pilihan seksi tujuan tersembunyi secara default dan baru muncul dengan animasi expand ketika tombol ditekan. Ini mencegah panel menjadi sangat panjang saat seksi banyak. `ChecklistControlPanel` juga dikonversi dari `StatelessWidget` ke `StatefulWidget` untuk menyimpan state expand lokal.

**Blocked by:** None (dapat dimulai sekarang, independen dari tiket lain).

**Status:** ready-for-agent

---

## Acceptance Criteria

- [ ] `ChecklistControlPanel` dikonversi dari `StatelessWidget` ke `StatefulWidget` dengan field lokal `bool _isSectionPickerExpanded = false`.
- [ ] `ChecklistControlPanel` mendapat dua parameter baru:
  - Daftar `ChecklistSection` yang tersedia di grup saat ini
  - Nama seksi aktif subjek yang sedang dibuka (untuk filter)
  - Callback untuk memindahkan subjek ke seksi tujuan yang dipilih
- [ ] Tombol atau baris "Pindah Seksi" (dengan ikon `Icons.drive_file_move_outlined` atau serupa) ditampilkan di panel, di area yang masuk akal secara visual bersama kontrol lainnya.
- [ ] Daftar seksi tujuan **tidak terlihat** saat `_isSectionPickerExpanded == false`.
- [ ] Ketuk "Pindah Seksi" → `_isSectionPickerExpanded` jadi `true`; daftar seksi muncul dengan `AnimatedSize` (durasi 200 ms, curve `Curves.easeInOut`), identik dengan pola `MoveSelectedItemsDialog`.
- [ ] Daftar hanya menampilkan seksi-seksi yang **bukan** seksi aktif subjek saat ini.
- [ ] Ketuk nama seksi tujuan dari daftar → callback pemindahan dipanggil → `_isSectionPickerExpanded` kembali `false` (picker tertutup) → dialog `DailyChecklistDialog` **tidak** ditutup otomatis.
- [ ] Ketuk "Pindah Seksi" lagi saat picker terbuka → picker tertutup (toggle).
- [ ] Widget test memverifikasi (menggunakan `DailyChecklistDialog` atau `ChecklistControlPanel` langsung dengan data stub):
  - Daftar seksi tidak ada di widget tree saat awal
  - Ketuk "Pindah Seksi" → daftar muncul; seksi aktif tidak ada di daftar
  - Ketuk seksi tujuan → callback dipanggil dengan seksi yang benar; picker tertutup
  - Ketuk "Pindah Seksi" lagi saat terbuka → daftar hilang
