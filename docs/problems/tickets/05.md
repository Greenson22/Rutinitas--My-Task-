# 05: ChecklistControlPanel — Pindah Seksi Lazy-Expand

**What to build:** Tambahkan tombol "Pindah Seksi" baru ke `ChecklistControlPanel` di dalam `DailyChecklistDialog`. Daftar pilihan seksi tujuan tersembunyi secara default dan baru muncul dengan animasi expand ketika tombol ditekan. Ini mencegah panel menjadi sangat panjang saat seksi banyak. `ChecklistControlPanel` juga dikonversi dari `StatelessWidget` ke `StatefulWidget` untuk menyimpan state expand lokal.

**Blocked by:** None (dapat dimulai sekarang, independen dari tiket lain).

**Status:** done

**Waktu Penyelesaian:** 2026-11-25 15:40 WITA

**Catatan Penyelesaian:**
- Mengonversi `ChecklistControlPanel` dari `StatelessWidget` menjadi `StatefulWidget` dengan state lokal `bool _isSectionPickerExpanded = false`.
- Menambahkan parameter `availableSections`, `currentSectionName`, dan `onMoveToSection` pada `ChecklistControlPanel`.
- Menambahkan tombol `Pindah Seksi` (ikon `Icons.drive_file_move_outlined`) dan daftar seksi tujuan yang dibungkus `AnimatedSize` (durasi 200 ms, curve `Curves.easeInOut`), memfilter seksi aktif saat ini, serta menutup picker setelah seksi tujuan dipilih atau saat tombol ditekan ulang.
- Menambahkan widget test di `test/features/checklist/checklist_control_panel_move_section_test.dart` (1/1 test lulus).

## Acceptance Criteria

- [x] `ChecklistControlPanel` dikonversi dari `StatelessWidget` ke `StatefulWidget` dengan field lokal `bool _isSectionPickerExpanded = false`.
- [x] `ChecklistControlPanel` mendapat dua parameter baru:
  - Daftar `ChecklistSection` yang tersedia di grup saat ini
  - Nama seksi aktif subjek yang sedang dibuka (untuk filter)
  - Callback untuk memindahkan subjek ke seksi tujuan yang dipilih
- [x] Tombol atau baris "Pindah Seksi" (dengan ikon `Icons.drive_file_move_outlined` atau serupa) ditampilkan di panel, di area yang masuk akal secara visual bersama kontrol lainnya.
- [x] Daftar seksi tujuan **tidak terlihat** saat `_isSectionPickerExpanded == false`.
- [x] Ketuk "Pindah Seksi" → `_isSectionPickerExpanded` jadi `true`; daftar seksi muncul dengan `AnimatedSize` (durasi 200 ms, curve `Curves.easeInOut`), identik dengan pola `MoveSelectedItemsDialog`.
- [x] Daftar hanya menampilkan seksi-seksi yang **bukan** seksi aktif subjek saat ini.
- [x] Ketuk nama seksi tujuan dari daftar → callback pemindahan dipanggil → `_isSectionPickerExpanded` kembali `false` (picker tertutup) → dialog `DailyChecklistDialog` **tidak** ditutup otomatis.
- [x] Ketuk "Pindah Seksi" lagi saat picker terbuka → picker tertutup (toggle).
- [x] Widget test memverifikasi (menggunakan `DailyChecklistDialog` atau `ChecklistControlPanel` langsung dengan data stub):
  - Daftar seksi tidak ada di widget tree saat awal
  - Ketuk "Pindah Seksi" → daftar muncul; seksi aktif tidak ada di daftar
  - Ketuk seksi tujuan → callback dipanggil dengan seksi yang benar; picker tertutup
  - Ketuk "Pindah Seksi" lagi saat terbuka → daftar hilang
