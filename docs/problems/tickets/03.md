# 03: SettingsDialog — Switch Default Collapse untuk Checklist Groups

**What to build:** Tambahkan satu switch baru di bagian "Tampilan Checklist" pada `SettingsDialog` untuk mengatur apakah seksi di Checklist Groups dimulai dalam kondisi tertutup atau terbuka secara default. Switch ini menulis ke kunci SharedPreferences yang berbeda dari kunci Checklist Detail yang sudah ada.

**Blocked by:** 01 (DailyController — State Collapse & Hidden Per-Seksi)

**Status:** done

**Waktu Penyelesaian:** 2026-11-25 15:28 WITA

**Catatan Penyelesaian:**
- Menambahkan state `_checklistGroupsDefaultCollapsed`, handler `_handleChecklistGroupsDefaultCollapsedToggle`, serta `ListTile` + `Switch` berlabel `'Checklist Groups: Tutup seksi secara default'` di bagian "Tampilan Checklist" pada `SettingsDialog`.
- Switch membaca dan menulis langsung ke `SharedPreferences` kunci `'checklist_groups_default_collapsed'` tanpa mengubah `'section_default_collapsed'`.
- Menambahkan widget test di `test/core/presentation/widgets/settings_dialog_checklist_groups_collapse_test.dart` (1/1 test lulus).
