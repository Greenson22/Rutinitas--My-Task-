# 03: SettingsDialog — Switch Default Collapse untuk Checklist Groups

**What to build:** Tambahkan satu switch baru di bagian "Tampilan Checklist" pada `SettingsDialog` untuk mengatur apakah seksi di Checklist Groups dimulai dalam kondisi tertutup atau terbuka secara default. Switch ini menulis ke kunci SharedPreferences yang berbeda dari kunci Checklist Detail yang sudah ada.

**Blocked by:** 01 (DailyController — State Collapse & Hidden Per-Seksi)

**Status:** ready-for-agent

---

## Acceptance Criteria

- [ ] `SettingsDialog` menampilkan switch baru berlabel `'Checklist Groups: Tutup seksi secara default'` di dalam bagian "Tampilan Checklist", di bawah dua switch yang sudah ada (Tutup seksi / Ingat status lipatan) untuk Checklist Detail.
- [ ] Switch membaca nilai awal dari SharedPreferences kunci `'checklist_groups_default_collapsed'` (default `false` = terbuka).
- [ ] Toggle switch menulis nilai baru ke `'checklist_groups_default_collapsed'` secara langsung (tanpa perlu menekan Simpan di bawah dialog).
- [ ] Subtitle switch menjelaskan dengan jelas bahwa ini berlaku untuk layar **Checklist Groups** (bukan Checklist Detail), untuk membedakan dari switch "Tutup seksi secara default" yang sudah ada.
- [ ] Kunci `'section_default_collapsed'` yang sudah ada (Checklist Detail) tidak terganggu atau dimodifikasi.
- [ ] Widget test memverifikasi:
  - Switch `'Checklist Groups: Tutup seksi secara default'` muncul di `SettingsDialog`
  - Toggle switch → SharedPreferences `'checklist_groups_default_collapsed'` berubah nilainya
  - Kunci `'section_default_collapsed'` tidak ikut berubah saat switch Groups di-toggle
