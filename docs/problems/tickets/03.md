# 03: Edit Hitungan Harian di Dialog Ubah Tugas (Task Master New)

**What to build:** Di layar detail kategori Task Master New, ketika pengguna membuka dialog "Ubah Tugas" (via menu ⋮ → Ubah), saat ini tidak ada cara untuk mengoreksi nilai hitungan harian yang sudah tercatat — hanya bisa increment satu per satu. Tiket ini menambahkan field "Hitungan Hari Ini" ke dialog tersebut (hanya saat mode edit, bukan tambah baru). Pengguna dapat mengubah nilai dari misalnya 320 menjadi 20 atau 0 secara langsung. Perubahan ini menyimpan entri `DailyProgress` baru untuk hari ini dan mengupdate `totalCount` tugas via delta (`newTotal = oldTotal - oldCount + newCount`). Semua field yang sudah ada (nama, jenis, target harian, target total, visibilitas, status aktif) tetap tidak berubah dan bisa diedit bersamaan. `TaskRepository` diperluas dengan method baru untuk update hitungan harian, dan `FakeTaskRepository` di test support ikut diperluas mengikuti pola yang ada.

**Blocked by:** None (dapat dimulai langsung)

**Status:** ready-for-agent

- [ ] Field "Hitungan Hari Ini" muncul di dialog Ubah Tugas saat mode edit
- [ ] Field tidak muncul saat mode Tambah Tugas Baru
- [ ] Nilai awal field diisi dengan hitungan hari ini yang sudah tercatat (`countOn(todayKey)`)
- [ ] Pengguna dapat mengubah nilai ke angka berapa pun termasuk 0
- [ ] Validasi menolak nilai negatif dan input bukan angka (pesan error inline)
- [ ] Menyimpan dialog dengan nilai hitungan yang berubah mengupdate `DailyProgress` hari ini di riwayat tugas
- [ ] `totalCount` tugas diupdate secara konsisten via delta (bukan replace)
- [ ] Bila nilai hitungan tidak diubah (sama dengan nilai lama), tidak ada operasi simpan tambahan yang dipicu untuk hitungan
- [ ] Semua field lain (nama, jenis, target, visibilitas, aktif) tetap bisa disimpan bersamaan
- [ ] `TaskRepository` memiliki method/operasi baru untuk update hitungan harian tugas
- [ ] `FakeTaskRepository` di test support mengimplementasikan method/operasi baru tersebut
- [ ] Widget test end-to-end memverifikasi: (a) field muncul di mode edit, (b) tidak muncul di mode tambah, (c) perubahan nilai tersimpan dengan delta `totalCount` yang benar, (d) validasi negatif menolak simpan
