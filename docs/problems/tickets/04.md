# 04: DailyScreen — Tombol Sembunyi Seksi di Edit Mode Header

**What to build:** Tambahkan tombol sembunyi seksi (ikon mata) di edit mode header seksi pada Checklist Groups. Ketika diaktifkan, header tetap tampil dengan badge "Tersembunyi" tapi semua card di bawah seksi tersebut hilang dari tampilan. State ini ephemeral (reset di restart). Fungsionalitas ini memanfaatkan prop `onToggleVisibility` dan `isHidden` yang sudah ada di `InteractiveSectionHeader`.

**Blocked by:** 02 (DailyScreen — Collapse Seksi) karena `InteractiveSectionHeader` harus sudah terpasang di `DailyScreen` sebelum prop visibility disambungkan.

**Status:** ready-for-agent

---

## Acceptance Criteria

- [ ] Di `DailyScreen`, prop `onToggleVisibility` pada `InteractiveSectionHeader` disambungkan ke `DailyController.toggleSectionHidden(sectionKey)`.
- [ ] Prop `isHidden` pada `InteractiveSectionHeader` disambungkan ke `DailyController.isSectionHidden(sectionKey)`.
- [ ] Callback `isSectionCollapsed` yang sudah ada di `GroupedSectionLayout` digabungkan: mengembalikan `true` jika seksi collapsed **atau** hidden (`isSectionCollapsed || isSectionHidden`).
- [ ] Header seksi yang di-hidden tetap dirender di layar (agar pengguna bisa men-toggle kembali), tapi semua card di bawahnya tidak tampil.
- [ ] `InteractiveSectionHeader` menampilkan badge "Tersembunyi" pada header yang `isHidden == true`, konsisten dengan tampilan di Checklist Detail.
- [ ] Tombol sembunyi **hanya muncul di edit mode** header (setelah long-press pada header seksi atau ketuk tombol edit), tidak terlihat di mode tampilan biasa.
- [ ] State hidden direset menjadi `false` untuk semua seksi ketika aplikasi dimulai ulang (ephemeral).
- [ ] Widget test memverifikasi:
  - Long-press header → edit mode → tombol sembunyi (tooltip "Sembunyikan Seksi") muncul
  - Ketuk tombol sembunyi → badge "Tersembunyi" muncul di header; card di bawah tidak ada di widget tree
  - Ketuk tombol unhide (tooltip "Tampilkan Seksi") → badge hilang; card kembali tampil
