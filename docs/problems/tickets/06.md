# 06: Task Master New — Pewarnaan Tile Selesai + Kartu Dashboard "X/Y"

**What to build:** Dua peningkatan visual terkait pada modul Task Master New: (a) tile tugas di daftar "Hari Ini" mendapat latar belakang hijau muda jika target hariannya sudah tercapai, dan (b) kartu "Target tercapai" di dashboard diubah menjadi format "X / Y" (tercapai / total di daftar Hari Ini) dengan warna dinamis.

**Blocked by:** None (dapat dimulai sekarang, independen dari tiket lain).

**Status:** done

**Waktu Penyelesaian:** 2026-11-25 15:50 WITA

**Catatan Penyelesaian:**
- Mengganti `Padding` terluar `TodayTaskTile` menjadi `Container` dengan `BoxDecoration` berwarna `const Color(0xFFE8F5E9)` saat `targetMet == true` dan `Colors.transparent` saat lainnya.
- Menambahkan parameter `todayTasksTotalCount` pada `DashboardSummaryCards`, mengubah nilai kartu `summaryCompletedTargets` menjadi `'$completedTargetsToday / $todayTasksTotalCount'`, serta mengubah warnanya menjadi `Colors.green[700]!` jika semua tugas selesai dan `Colors.orange[800]!` selain itu.
- Meneruskan `todayTasksTotalCount: todayTasks.length` dari `TaskMasterNewScreen` (layout single-pane maupun desktop) ke `DashboardSummaryCards`.
- Memperbarui ekspektasi di `dashboard_test.dart` (6/6 lulus) dan menambahkan `today_task_tile_and_summary_test.dart` (6/6 lulus).

## Acceptance Criteria

### Bagian A — Pewarnaan TodayTaskTile

- [x] Widget `TodayTaskTile` merender container terluar dengan warna latar `const Color(0xFFE8F5E9)` (Material Green 50) ketika `isTaskTargetMetToday(task, todayKey) == true`.
- [x] Widget `TodayTaskTile` merender container terluar transparan (tidak berwarna) untuk tile dengan target belum tercapai atau tanpa target sama sekali.
- [x] Teks, ikon, dan elemen UI lain di dalam tile tidak berubah tampilan akibat pewarnaan ini.
- [x] Widget test memverifikasi (dengan `FakeTaskRepository`):
  - Tile tugas yang `targetMet == true` memiliki ancestor `Container` dengan `Color(0xFFE8F5E9)`
  - Tile tugas yang `targetMet == false` tidak memiliki latar hijau
  - Tile tugas tanpa target (`TaskKind.counter` tanpa `targetDaily`) tidak memiliki latar hijau

### Bagian B — Kartu Dashboard "X/Y"

- [x] `DashboardSummaryCards` mendapat satu parameter baru `int todayTasksTotalCount`.
- [x] Nilai kartu ketiga (key `summaryCompletedTargets`) ditampilkan sebagai `'$completedTargetsToday / $todayTasksTotalCount'` (misalnya "2 / 5").
- [x] Warna kartu ketiga bersifat dinamis:
  - `Colors.green[700]!` ketika `completedTargetsToday == todayTasksTotalCount && todayTasksTotalCount > 0` (semua selesai)
  - `Colors.orange[800]!` selain itu (termasuk `todayTasksTotalCount == 0`)
- [x] `TaskMasterNewScreen` menghitung `todayTasksTotalCount` dari `todayTasks.length` dan meneruskannya ke `DashboardSummaryCards`, baik di layout single-pane maupun desktop.
- [x] Ketika tidak ada tugas di daftar Hari Ini (`todayTasksTotalCount == 0`), kartu menampilkan `'0 / 0'` tanpa crash.
- [x] Widget test memverifikasi (extend `dashboard_test.dart` yang sudah ada):
  - Nilai kartu `summaryCompletedTargets` menampilkan format `"X / Y"` bukan hanya `"X"`
  - Dengan semua tugas tercapai → warna kartu hijau
  - Dengan sebagian tugas tercapai → warna kartu oranye
  - Dengan tanpa tugas hari ini → nilai `"0 / 0"`, tidak crash
