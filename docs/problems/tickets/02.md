# 02: Tombol Aksi Seksi Checklist via Long Press

**What to build:** Di layar detail checklist (`ChecklistDetailScreen`), setiap header `ChecklistSection` saat ini selalu menampilkan tombol aksi (Sembunyikan, Pindah Atas, Pindah Bawah, Ubah Nama, Hapus, Tambah Materi) di samping nama seksi — menyebabkan layout rusak saat nama panjang dan tampilan klutter. Tiket ini menyembunyikan semua tombol aksi by default dan memunculkannya hanya saat pengguna melakukan long press pada header seksi tersebut. Tombol aksi muncul **di bawah** nama seksi (bukan di sampingnya) dalam layout yang bisa wrap ke baris berikutnya bila layar sempit. Long press kedua pada header yang sama menyembunyikan tombol kembali. State ini sepenuhnya UI-only — tidak ada perubahan ke model data `ChecklistSection` atau file JSON.

**Blocked by:** None (dapat dimulai langsung)
