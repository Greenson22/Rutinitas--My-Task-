# 02: DailyScreen — Collapse Seksi (Ketuk Header + Ikon Chevron)

**What to build:** Hubungkan state collapse dari `DailyController` ke `DailyScreen` sehingga pengguna dapat mengetuk header seksi di Checklist Groups untuk menyembunyikan dan menampilkan kembali semua card di bawahnya. Header seksi dimigrasi dari builder inline saat ini ke `InteractiveSectionHeader` yang sudah ada di `core/presentation/widgets/`.

**Blocked by:** 01 (DailyController — State Collapse & Hidden Per-Seksi)

**Status:** done

**Waktu Penyelesaian:** 2026-11-25 15:23 WITA

**Catatan Penyelesaian:**
- Menyambungkan `isSectionCollapsed: (sectionKey) => _controller.isSectionCollapsed(sectionKey)` pada `GroupedSectionLayout<ChecklistGroup>` di `DailyScreen` (`checklist_screen.dart`).
- Menyambungkan `isCollapsed` dan `onToggleCollapse` pada `InteractiveSectionHeader` di `DailyScreen` ke `DailyController`.
- Menambahkan widget test di `test/features/checklist/daily_screen_collapse_test.dart` (2/2 test lulus).

---

## Acceptance Criteria

- [x] `DailyScreen` menyambungkan callback `isSectionCollapsed` ke `GroupedSectionLayout` menggunakan state dari `DailyController.isSectionCollapsed(sectionKey)`.
- [x] `DailyScreen` menggunakan `InteractiveSectionHeader` sebagai builder header seksi, dengan `themeColor: Colors.indigo` (menggantikan header inline yang sebelumnya ada).
- [x] `InteractiveSectionHeader` dipasang dengan prop `isCollapsed` dan `onToggleCollapse` yang terhubung ke `DailyController`.
- [x] Ketika pengguna mengetuk header seksi yang terbuka, semua card `ChecklistGroup` di bawahnya menghilang dari widget tree dengan animasi `AnimatedCrossFade` yang sudah ada di `GroupedSectionLayout`.
- [x] Ikon chevron di header menampilkan `Icons.expand_more` (terbuka) dan `Icons.chevron_right` (tertutup), konsisten dengan perilaku di Checklist Detail.
- [x] Ketika pengguna mengetuk kembali header yang tertutup, card muncul kembali.
- [x] State collapse dipertahankan saat scroll naik-turun (tidak reset karena scroll).
- [x] Widget test memverifikasi (menggunakan `DailyScreen` atau `GroupedSectionLayout` dengan data stub):
  - Ketuk header seksi → card di bawahnya tidak ada di widget tree; chevron berubah ke `►`
  - Ketuk header lagi → card muncul kembali; chevron kembali ke `▼`
  - Dengan `'checklist_groups_default_collapsed': true` → seksi langsung tertutup saat widget pertama dirender
