# 01: DailyController — State Collapse & Hidden Per-Seksi

**What to build:** Tambahkan logika state ephemeral untuk collapse dan sembunyi seksi ke dalam `DailyController`. Pengguna di tiket-tiket selanjutnya akan menggunakan state ini dari layar Checklist Groups. Tidak ada perubahan UI di tiket ini — murni logika controller.

**Blocked by:** None (dapat dimulai sekarang).

**Status:** done

**Waktu Penyelesaian:** 2026-11-25 15:08 WITA

**Catatan Penyelesaian:**
- Menambahkan state ephemeral `_collapsedSections` dan `_hiddenSections` (`Map<String, bool>`) serta `_defaultCollapseState` di `DailyController`.
- Menambahkan method `isSectionCollapsed`, `toggleSectionCollapsed`, `isSectionHidden`, dan `toggleSectionHidden` di `DailyController`.
- Membaca kunci `checklist_groups_default_collapsed` dari `SharedPreferences` pada pemanggilan pertama `loadGroupsData()` tanpa mereset state ephemeral saat reload.
- Menambahkan unit test di `test/features/checklist/daily_controller_section_state_test.dart` (5/5 test lulus, `flutter analyze` 0 issues).

---

## Acceptance Criteria

- [x] `DailyController` memiliki dua `Map<String, bool>` ephemeral: satu untuk state collapse per-seksi, satu untuk state hidden per-seksi. Keduanya tidak ditulis ke disk dan direset tiap kali controller diinisialisasi ulang.
- [x] `DailyController` menyediakan empat method publik:
  - `bool isSectionCollapsed(String sectionKey)` — membaca dari map collapse, fallback ke `defaultCollapseState`
  - `void toggleSectionCollapsed(String sectionKey)` — flip nilai di map, panggil `notifyListeners()`
  - `bool isSectionHidden(String sectionKey)` — membaca dari map hidden, default `false`
  - `void toggleSectionHidden(String sectionKey)` — flip nilai di map, panggil `notifyListeners()`
- [x] `DailyController` membaca nilai default collapse dari SharedPreferences dengan kunci `'checklist_groups_default_collapsed'` (berbeda dari `'section_default_collapsed'` yang dipakai Checklist Detail) saat `loadGroupsData()` pertama kali dipanggil. Default fallback: `false` (terbuka).
- [x] Ketika `loadGroupsData()` dipanggil ulang (reload data), state ephemeral collapse dan hidden **tidak direset** — state dipertahankan selama sesi.
- [x] Widget test atau unit test memverifikasi:
  - `isSectionCollapsed` mengembalikan `defaultCollapseState` untuk seksi yang belum pernah di-toggle
  - `toggleSectionCollapsed` dua kali mengembalikan ke state awal
  - `isSectionHidden` mengembalikan `false` untuk seksi yang belum pernah di-toggle
  - Dengan mock SharedPreferences `'checklist_groups_default_collapsed': true`, `isSectionCollapsed` pada seksi baru mengembalikan `true`
