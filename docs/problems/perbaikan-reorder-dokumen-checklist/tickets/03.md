# 03: Folder Bertingkat — Navigasi, Buat, Rename, Pindah, Hapus

**What to build:** Di dalam setiap group My Documents, pengguna bisa membuat folder, membuat folder di dalam folder tanpa batas kedalaman, lalu menjelajahinya lewat drill-down dengan breadcrumb. Folder selalu tampil di atas berkas. Folder bisa diubah nama, diganti induknya di group yang sama, dan dihapus beserta seluruh isinya dengan konfirmasi. Berkas lama tetap tampil di layar group tanpa migrasi.

**Blocked by:** 01

**Status:** done

- [x] Metadata folder (id, nama, ikon, parent, urutan) tersimpan di dalam data group dan terbaca kembali.
- [x] Data group lama tanpa metadata folder dibaca sebagai daftar folder kosong.
- [x] Setiap folder dipetakan ke direktori fisik; subfolder menghasilkan struktur direktori bersarang.
- [x] Layar group menampilkan breadcrumb Group / Folder / Subfolder; setiap segmen bisa ditekan untuk naik.
- [x] Tap folder membuka isi folder; tombol back kembali ke folder induk.
- [x] Folder tampil sebelum berkas; berkas mengikuti mode pengurutan yang sudah ada.
- [x] Ringkasan isi folder menampilkan jumlah berkas dan subfolder langsung.
- [x] Membuat folder dengan nama yang sudah dipakai saudaranya (tanpa membedakan huruf besar/kecil) ditolak dengan pesan jelas.
- [x] Nama folder disanitasi dari karakter path terlarang.
- [x] Ubah nama folder ikut mengganti nama direktori fisik beserta isinya.
- [x] Pindah folder hanya bisa ke parent lain di group yang sama; memindah ke dirinya sendiri atau turunannya ditolak.
- [x] Hapus folder memakai konfirmasi destruktif dan menghapus seluruh isi secara rekursif.
- [x] Berkas dan folder lama di root group tetap tampil tanpa migrasi paksa.
