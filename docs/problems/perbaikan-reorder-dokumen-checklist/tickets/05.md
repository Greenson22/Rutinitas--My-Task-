# 05: Picker Emoji untuk Ikon Group & Folder

**What to build:** Saat membuat atau mengubah group maupun folder, pengguna memilih ikon dari grid emoji terkurasi, bukan mengetik emoji bebas. Ikon lama yang tidak ada di daftar tetap ditampilkan dan dianggap valid. Tampilan kartu group dan baris folder langsung mengikuti ikon yang dipilih.

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] Ada satu widget picker emoji yang dipakai bersama oleh dialog group dan dialog folder.
- [ ] Picker menampilkan grid emoji terkurasi dan menandai pilihan aktif.
- [ ] Memilih emoji menyimpan nilai ke data group atau metadata folder.
- [ ] Dialog tambah/edit group memakai picker, bukan input teks emoji.
- [ ] Dialog tambah/edit folder memakai picker yang sama.
- [ ] Emoji lama di luar daftar kurasi tetap tampil dan tersimpan tanpa error.
- [ ] Ikon baru langsung terlihat pada kartu group atau baris folder setelah disimpan.
