# 07: Tautan Berkas Checklist — Pilih, Simpan, Buka, Lepas

**What to build:** Pengguna bisa menautkan satu berkas My Documents ke satu item checklist lewat dialog "Ubah Item & Hubungan Lintas Data", memilih berkas melalui penjelajah Group → Folder → Berkas dengan pencarian. Item yang tertaut menampilkan indikator 📎 dan punya entri "Buka Berkas" di titik tiga. Pelepasan tautan dilakukan di dialog yang sama dengan konfirmasi.

**Blocked by:** 01, 03

**Status:** ready-for-agent

- [ ] Item checklist menyimpan ID group dokumen, path relatif berkas, dan nama tampilan berkas.
- [ ] Item lama tanpa field tautan tetap terbaca dan tidak berubah tampilannya.
- [ ] Dialog Ubah Item & Hubungan Lintas Data menampilkan bagian berkas tertaut.
- [ ] Tombol pilih/ganti berkas membuka penjelajah hierarkis Group → Folder → Berkas dengan breadcrumb dan pencarian.
- [ ] Penjelajah hanya mengizinkan pemilihan berkas, bukan folder.
- [ ] Menyimpan dialog mengisi field tautan dan menampilkannya saat dialog dibuka kembali.
- [ ] Tombol hapus kaitan memakai dialog konfirmasi destruktif dan mengosongkan ketiga field.
- [ ] Menekan Batal di dialog tidak mengubah tautan apa pun.
- [ ] Item tertaut menampilkan indikator 📎 di barisnya.
- [ ] Entri "Buka Berkas" hanya muncul di titik tiga saat item punya tautan dan membuka berkas dengan aplikasi eksternal.
- [ ] Berkas yang sudah tidak ada ditandai "Berkas tidak ditemukan" dan menawarkan opsi lepas.
- [ ] Relasi checklist lama (akumulasi, prasyarat, lintas card) tetap berfungsi.
