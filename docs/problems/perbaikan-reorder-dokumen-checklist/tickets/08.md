# 08: Propagasi Tautan & Status Berkas Hilang

**What to build:** Tautan berkas di item checklist tetap benar ketika berkas atau foldernya diubah dari dalam aplikasi. Rename dan pindah memperbarui path tautan, sedangkan hapus dari dalam aplikasi melepas tautan otomatis dengan notifikasi. Berkas yang hilang karena perubahan di luar aplikasi tidak merusak data, tetapi ditandai dan bisa dilepas pengguna.

**Blocked by:** 03, 04, 07

**Status:** done

- [x] Rename berkas memperbarui path relatif dan nama tampilan pada semua item yang tertaut.
- [x] Pindah berkas ke folder atau group lain memperbarui ID group dan path relatif pada semua item yang tertaut.
- [x] Rename folder memperbarui prefix path pada semua tautan di bawahnya.
- [x] Pindah folder memperbarui prefix path pada semua tautan di bawahnya.
- [x] Hapus berkas melepas tautan terkait dan menampilkan notifikasi informasi.
- [x] Hapus folder melepas semua tautan di subtree-nya.
- [x] Hapus group melepas semua tautan yang menunjuk ke group tersebut.
- [x] Dua berkas bernama sama di folder berbeda tidak tertukar saat propagasi.
- [x] Berkas yang hilang karena aksi di luar aplikasi tidak mengubah data; item menampilkan status tidak ditemukan dan opsi lepas.
- [x] Penulisan propagasi memakai jalur penyimpanan checklist yang sama, termasuk enkripsi, dan bersifat atomik.
- [x] Tidak ada tautan yang tersisa menunjuk ke path yang sudah tidak ada setelah aksi internal.
