# 01: Prefactor — Ekstrak Layanan Penyimpanan Berkas Dokumen

**What to build:** Seluruh operasi filesystem dokumen (membaca isi direktori, impor, ubah nama, pindah, hapus, resolusi path relatif/absolut, dan penanganan nama bentrok) dipindahkan dari layar ke satu layanan yang bisa dipakai ulang dan diuji tanpa widget.
