# 01: Prefactor — Ekstrak Layanan Penyimpanan Berkas Dokumen

**What to build:** Seluruh operasi filesystem dokumen (membaca isi direktori, impor, ubah nama, pindah, hapus, resolusi path relatif/absolut, dan penanganan nama bentrok) dipindahkan dari layar ke satu layanan yang bisa dipakai ulang dan diuji tanpa widget. Perilaku yang terlihat pengguna tidak berubah: layar group tetap bisa menampilkan, membuka, mengimpor, mengubah nama, memindahkan, dan menghapus berkas seperti sebelumnya.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Layar detail group memakai layanan baru untuk semua operasi berkas, tanpa regresi perilaku.
- [ ] Layanan menerima base directory yang di-inject dan tidak membaca konfigurasi global tersembunyi.
- [ ] Operasi list, impor, rename, pindah, dan hapus dapat dipanggil tanpa membangun widget.
- [ ] Format data group dan struktur direktori tidak berubah.
- [ ] Test perilaku lama untuk impor, rename, pindah, dan hapus tetap lulus.
