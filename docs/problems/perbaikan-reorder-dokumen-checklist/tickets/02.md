# 02: Urutan Hari Ini Permanen — Task Master Schema v3

**What to build:** Pengguna bisa menggeser tugas di seksi Hari Ini, dan urutan itu tetap sama setelah keluar-masuk layar maupun menutup dan membuka aplikasi. Mode pengurutan terakhir juga dipulihkan. Urutan Hari Ini sepenuhnya independen dari urutan tugas di dalam kategori. Data tugas lama tetap terbaca setelah pembaruan.

**Blocked by:** None (can start immediately)

**Status:** done

- [x] Data tugas mendapat `todaySortMode` dan `todayOrder`, dengan schema version 3.
- [x] Data schema 1/2 dimigrasikan otomatis tanpa mengubah kategori, tugas, atau riwayat.
- [x] Menggeser tugas (drag maupun tombol naik/turun) langsung menyimpan urutan.
- [x] Mengubah mode pengurutan menyimpan mode terakhir.
- [x] Urutan dan mode bertahan setelah layar dibangun ulang dan setelah aplikasi dibuka kembali.
- [x] Tugas baru muncul di akhir urutan; ID tugas yang sudah dihapus dibersihkan.
- [x] Tugas yang sedang tidak tampil hari ini tetap mempertahankan posisinya saat muncul kembali.
- [x] Mode custom dengan urutan kosong berperilaku seperti mode default.
- [x] Menggeser tugas di Hari Ini tidak mengubah urutan tugas di Category Detail.
- [x] Nilai mode yang tidak dikenal saat membaca data jatuh ke mode default tanpa crash.
