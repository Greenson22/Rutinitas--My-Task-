# 04: Berkas di Dalam Folder — Impor, Rename, Pindah, Auto-rename

**What to build:** Pengguna bisa mengimpor berkas langsung ke folder yang sedang dibuka, mengubah nama berkas, dan memindahkannya ke folder lain atau ke group lain. Nama yang bentrok di folder yang sama otomatis mendapat akhiran `(1)`, `(2)`, dan seterusnya tanpa dialog. Dua berkas bernama sama di folder berbeda tetap aman dan tidak saling menimpa.

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] Impor berkas menargetkan folder aktif, bukan selalu root group.
- [ ] Impor dua berkas bernama sama di folder yang sama menghasilkan `nama (1).ext`, lalu `nama (2).ext`.
- [ ] Impor berkas bernama sama ke folder berbeda mempertahankan nama asli.
- [ ] Ubah nama berkas yang bentrok di folder yang sama otomatis memakai akhiran angka.
- [ ] Pemindahan berkas memakai pemilih tujuan Group → Folder.
- [ ] Pemindahan lintas group dan lintas folder berhasil memindahkan berkas secara fisik.
- [ ] Pemindahan yang menemukan nama bentrok di tujuan memakai akhiran angka, bukan menimpa.
- [ ] Hapus berkas tetap memakai konfirmasi dan menghapus berkas fisik.
- [ ] Multi-select tetap hanya mencakup berkas pada folder aktif.
