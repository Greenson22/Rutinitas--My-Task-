# 06: Hapus Ekspor & Bagikan Folder sebagai ZIP

**What to build:** Aksi Ekspor di My Documents hilang dari menu berkas maupun aksi massal, dan digantikan oleh Bagikan Berkas yang sudah ada. Pengguna juga bisa membagikan satu folder sebagai ZIP berisi seluruh subfolder dan isinya dengan struktur yang tetap utuh, termasuk folder kosong. Backup/restore di Data Center tidak berubah.

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] Menu Ekspor per berkas tidak lagi tampil di My Documents.
- [ ] Aksi ekspor massal tidak lagi tersedia di My Documents.
- [ ] Bagikan per berkas dan bagikan massal berkas tetap berfungsi.
- [ ] Menu folder menyediakan Bagikan (ZIP).
- [ ] ZIP folder memuat seluruh subtree dengan struktur relatif terjaga.
- [ ] Folder kosong tetap menghasilkan ZIP yang valid.
- [ ] Nama berkas ZIP mengikuti nama folder yang dibagikan.
- [ ] Berkas ZIP sementara dibersihkan setelah proses bagikan.
- [ ] Data Center tetap memiliki backup/restore dan ekspor per fitur seperti sebelumnya.
