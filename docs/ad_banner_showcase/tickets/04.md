# 04: Test Unit & Widget — AdShowcaseController, DrawerMenu, SettingsDialog, Screen

**What to build:** Tambahkan coverage test untuk semua modul baru dan modul yang dimodifikasi dalam fitur Ad Banner Showcase. Gunakan `SharedPreferences.setMockInitialValues` untuk mengisolasi state SharedPreferences di setiap test. Hindari mock terhadap AdMob SDK — gunakan guard platform yang sudah ada atau simulasi `Platform.isAndroid = false`. Test hanya menguji perilaku yang terlihat dari luar: nilai yang dikembalikan, perubahan state, dan widget yang muncul di tree.

**Cakupan yang dibutuhkan:**

**Unit test `AdShowcaseController`:**
- Membaca interval dari SharedPreferences dengan benar saat init (termasuk nilai default 60 jika belum ada).
- `refreshKey` naik dari 0 ke 1 saat `triggerManualRefresh()` dipanggil.
- `setInterval(seconds)` menyimpan nilai ke SharedPreferences dan nilai terbaru terbaca kembali.
- Nilai di luar rentang diklem (misalnya `setInterval(10)` → tersimpan 30, `setInterval(999)` → tersimpan 300).
- `dispose()` tidak melempar exception.

**Widget test `DrawerMenu`:**
- Jika SharedPreferences `enable_ad_banner_showcase = true`, entri menu "Ad Banner Showcase" muncul di tree.
- Jika SharedPreferences `enable_ad_banner_showcase = false`, entri menu "Ad Banner Showcase" tidak ada di tree.

**Widget test `SettingsDialog`:**
- Switch "Ad Banner Showcase" muncul di dialog.
- Mengetuk switch dari off ke on menyimpan `enable_ad_banner_showcase = true` ke SharedPreferences.
- Mengetuk switch dari on ke off menyimpan `enable_ad_banner_showcase = false` ke SharedPreferences.

**Widget test `AdBannerShowcaseScreen`:**
- Semua 9 label slot muncul di tree (Task Master, MyChecklist Hub, MyChecklist Detail, MyNote Hub, MyNote Detail, MyPrompt Hub, MyPrompt Detail, My Documents, Data Center).
- `DropdownButton` interval muncul dan menampilkan nilai 60 sebagai default.
- Halaman tidak crash saat di-render di lingkungan non-Android (tidak ada `google_mobile_ads` yang aktif).
