# 01: AdShowcaseController — Logika Interval & Refresh

**What to build:** Buat controller pure-Dart (`AdShowcaseController`) yang mengelola seluruh logika refresh interval untuk halaman Ad Banner Showcase. Saat controller diinisialisasi, ia membaca nilai interval terakhir dari penyimpanan persisten (default 60 detik, rentang 30–300 detik). Controller menjalankan timer periodik; setiap kali timer tiba, ia menaikkan `refreshKey` — nilai yang nantinya dipakai layar untuk memaksa rebuild widget banner. Controller juga menyediakan getter countdown (berapa detik tersisa hingga refresh berikutnya, diperbarui tiap detik), metode `triggerManualRefresh()` untuk refresh segera tanpa menunggu timer, dan metode `setInterval(int seconds)` yang menyimpan nilai baru ke penyimpanan persisten lalu me-reset timer. Saat controller di-dispose, semua timer dibersihkan tanpa melempar error.

**Blocked by:** None (dapat dimulai segera)

**Status:** ready-for-agent

- [ ] Controller dapat dibuat tanpa UI dan tanpa AdMob SDK.
- [ ] `refreshKey` bernilai 0 saat pertama init, naik 1 setiap timer tiba.
- [ ] Interval dibaca dari SharedPreferences saat init; nilai default 60 dipakai jika belum pernah disimpan.
- [ ] `setInterval(seconds)` menyimpan nilai ke SharedPreferences dan mereset timer dengan durasi baru.
- [ ] `triggerManualRefresh()` menaikkan `refreshKey` dan mereset countdown tanpa menunggu timer.
- [ ] Countdown getter mengembalikan detik tersisa yang akurat (turun dari `interval` ke 0).
- [ ] `dispose()` membatalkan semua timer yang aktif dan tidak melempar exception.
- [ ] Nilai interval di luar rentang 30–300 diklem ke batas terdekat saat `setInterval` dipanggil.
